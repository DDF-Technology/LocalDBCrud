# Security policy

LocalDBCrudDemo è un progetto didattico locale e non deve essere usato per conservare credenziali o
dati reali. Segnalare privatamente eventuali vulnerabilità tramite il modulo contatti di
https://www.ddf.technology/ senza pubblicare database, password o informazioni personali.

La configurazione usa autenticazione integrata Windows verso SQL Server Express LocalDB. Nessuna
credenziale di database, telemetria o servizio remoto è inclusa nel progetto.
