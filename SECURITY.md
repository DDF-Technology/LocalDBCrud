# Security policy

LocalDBCrud è un progetto didattico locale e non deve essere usato senza revisione per conservare
dati reali o operare in ambienti di produzione. Segnalare privatamente eventuali vulnerabilità
tramite il modulo contatti di https://www.ddf.technology/ senza pubblicare database o informazioni
personali.

La configurazione usa l'autenticazione integrata Windows verso SQL Server Express LocalDB. Non sono
presenti account applicativi, credenziali, telemetria o servizi remoti.
