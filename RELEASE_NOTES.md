# LocalDBCrudDemo 1.0.0

Prima release pubblica MIT del dimostratore WinForms CRUD.

## Contenuto

- applicazione Windows compilata per .NET Framework 4.8;
- database SQL Server Express LocalDB creato automaticamente al primo avvio;
- tre prodotti fittizi e utente iniziale `demo` / `demo`;
- CRUD prodotti, ricerca, ordinamento e gestione utenti;
- export CSV e XLSX;
- documentazione e attribuzioni delle dipendenze.

## Requisito esterno

Installare SQL Server Express LocalDB (`MSSQLLocalDB`) prima dell'avvio.

## Avvertenza

Build non firmata e destinata esclusivamente ad apprendimento e test locali. Non usare dati reali
o credenziali riutilizzate altrove.
