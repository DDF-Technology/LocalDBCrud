# LocalDBCrud 1.0.0

Prima release pubblica MIT dell'esempio WinForms dedicato alle operazioni CRUD su database locale.

## Contenuto

- applicazione Windows compilata per .NET Framework 4.8;
- database SQL Server Express LocalDB creato automaticamente al primo avvio;
- tabella `Prodotti` con tre record esclusivamente fittizi;
- inserimento, lettura, modifica ed eliminazione dei prodotti;
- ricerca, ordinamento ed export CSV/XLSX;
- avvio diretto dell'interfaccia, senza gestione utenti o autenticazione;
- documentazione e attribuzioni delle dipendenze.

## Requisito esterno

Installare SQL Server Express LocalDB (`MSSQLLocalDB`) prima dell'avvio.

## Avvertenza

Build non firmata e destinata ad apprendimento e test locali. Non usare dati reali o ambienti di
produzione senza una revisione progettuale adeguata.
